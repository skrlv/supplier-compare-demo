# Сверка: от разных прайсов к сопоставимой закупке

Демонстрационная продуктовая работа, не проект реального клиента. Задача — сопоставить позиции из разных таблиц и показать платёж по одинаковой потребности с явными условиями.

В интерфейсе есть импорт CSV/TSV/XLSX, выбор листа и назначения колонок, каталог, очередь проверки, отдельные правки, ручные решения с основаниями, экспорт и восстановление. Движок использует точные дроби для упаковок/шага и денег; ставки задаются явно, валюты не смешиваются. Неизвестное условие не считается бесплатным. Название оборудования не доказывает взаимозаменяемость.

Проверяемый пример: при потребности 250 шт. упаковка по 100 шт. с ценой 850 RUB и доставкой 300 RUB требует трёх упаковок и платежа 2850 RUB. Цена 500 RUB за упаковку при MOQ 10 даёт 5000 RUB, хотя цена базовой штуки ниже. USD имеет отдельный рейтинг. Все эти цены и ставки вымышлены.

Данные находятся в памяти вкладки. JSON сохраняет оригиналы, источники, исправления и историю оснований; отпечаток SHA-256 обнаруживает изменение условий/каталога. Подлинность решения пользователя, права доступа и договорная пригодность этим не доказываются. Для реальной закупки человек проверяет модель, документы, место/базис поставки и одинаковое событие отсчёта срока.

Браузерное демо: https://skrlv.github.io/supplier-compare-demo/ . Исходники: https://github.com/skrlv/supplier-compare-demo . Локальный Node API запускается отдельно и не выдаётся за функцию GitHub Pages. Нет отправки поставщикам, заказов, общей базы и автоматического исследования реальных цен.

В проекте проверяются расчётная матрица A–G, ручные решения и их актуальность, дубли/конфликты, повреждённые файлы, формулы, атомарность ошибок, реальные выгрузки и возврат сессии. Отдельный итоговый QA-отчёт и версия публикации передаются рядом с проектом.
