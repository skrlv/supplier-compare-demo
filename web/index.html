Как устроен расчёт

Сначала точное соответствие

Автоматическое сопоставление использует только точный общий код каталога с отметкой sku_scope=catalog. Название и синонимы дают лишь кандидатов, а коды поставщика не считаются общими. Похожие названия и конфликты отправляются на проверку. Подтверждение человеком не отключает проверку единиц и обязательных условий.

От цены к стоимости закупки

Цена базовой единицы = цена с НДС ÷ содержимое единицы продажи. Количество единиц продажи = округление вверх до шага заказа от максимума потребности и минимального заказа. Итого = единицы продажи × цена с НДС + доставка.

Минимальный заказ и шаг задаются в единицах продажи. Например: упаковка по 100 шт., минимум 2 упаковки, шаг 1. При потребности 250 шт. нужно заказать 3 упаковки, придёт 300 шт.

Сравнимые условия

Валюты сравниваются отдельно. НДС для цены без налога рассчитывается только по явно заданной ставке, без предположений о законе или стране. Неизвестная доставка, срок или минимум блокируют расчёт. Диапазон срока оценивается по верхней границе в календарных днях.

Доставка относится к отдельному заказу одного товара. Итоги по разным товарам не складываются в стоимость общей корзины. Результат не учитывает наличие, договорные скидки, качество, пошлины и оплату частями.

Работа с файлами

Поддерживаются CSV, TSV и XLSX, доступны выбор листа и назначение столбцов. Формулы в ячейках XLSX не исполняются и отклоняются. Старый XLS предварительно сохраните как XLSX или CSV. Таблицы обрабатываются в браузере; отдельный локальный API описан в README.

Сохранение

Состояние хранится только до закрытия вкладки. Скачайте JSON для продолжения сессии и CSV для анализа. Данные сессии можно восстановить через кнопку «Восстановить JSON» в экспорте. Исправления и основания решений сохраняются отдельно от исходных строк.

Сохранить результат

JSON сохраняет исходные строки, исправления, решения с основаниями и расчёт. CSV содержит плоскую сводку, исходные данные и ошибки. Для продолжения используйте JSON.
