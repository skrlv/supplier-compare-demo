# Формат таблиц

Одна строка заголовков, затем записи. Английские поля назначаются автоматически; русские заголовки можно назначить в окне импорта. Повторные заголовки, назначения одного поля из нескольких колонок и повторные ID отклоняются. Пустые условия не превращаются в нули.

Каталог: `id,sku,name,base_unit,required_qty,aliases`. `aliases` — необязательные синонимы через `|`, служат для подбора кандидатов. Код `sku` общий для сопоставления с `sku_scope=catalog`. Не используйте в этой роли несогласованный код поставщика.

Прайс: `id,supplier,sku,sku_scope,supplier_sku,name,price,price_unit,pack_size,content_unit,currency,tax_mode,vat_rate,min_order,order_step,lead_days,shipping`.

- `sku_scope=catalog` явно подтверждает, что `sku` — код согласованного каталога; пусто оставляет ручную проверку. `supplier_sku` — отдельный код поставщика.
- `price_unit`: шт/кг/г/л/мл/м/см/мм/м²/упак/короб и поддержанные алиасы движка.
- Для упаковки `pack_size` — положительное содержимое, `content_unit` — физическая единица. Например, коробка 10×100 шт. записывается `pack_size=1000,content_unit=шт`. Для физических единиц оба поля пусты.
- `min_order,order_step` положительные и в единице продажи. MOQ 300 шт. при цене за 100 шт./упак сначала переведите в 3 упаковки.
- `price,shipping` неотрицательные, явный 0 допустим. `shipping` включает применимые налоги и относится к одному товару в валюте строки.
- `currency` — явный код валюты. Перечень разрешённых кодов определяет `supportedCurrencies` в движке; RUB, USD, EUR, CNY, KZT и другие. Курсов нет.
- `tax_mode=included` или `excluded`; для excluded обязательна ставка `vat_rate` 0…100. `unknown`/пусто требуют уточнения.
- `lead_days` — число календарных дней ≥0 или диапазон `3–5` от одинакового события. «От 5», «в наличии», даты и рабочие дни не поддерживаются.

Явные ID уникальны во всей сессии; без ID генерируется стабильный ID в области содержимого файла/листа/строки. Повтор файла отклоняется, а не удваивает предложения. Изменённая версия с прежними ID требует отдельного решения пользователя: текущий инструмент предлагает сохранить JSON и начать новую сессию. Каталоги добавляются, не заменяются автоматически. Для полной замены очистите сохранённую сессию.

Программа не доказывает взаимозаменяемость оборудования: точная спецификация, производитель, модель и допустимый аналог проверяются человеком и записываются в основании. Правка предложения хранится отдельно от `_source.original`; после правки ручное решение требует повторного подтверждения; прежнее основание остаётся в истории. В JSON сохраняется полный отпечаток исходных условий и каталога для проверки актуальности основания. Изменение количества не меняет идентичность товара и просто пересчитывает итог.
