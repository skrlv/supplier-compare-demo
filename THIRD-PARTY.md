# Сторонние компоненты

Проверено 16.11.2026 по официальным первичным источникам.

## ExcelJS 4.4.0

Используется для чтения XLSX в браузере и Node.js. CSV/TSV, проверка ZIP-лимитов, назначения столбцов и источники строк реализованы в проекте отдельно.

- Официальный проект: [exceljs/exceljs](https://github.com/exceljs/exceljs).
- Документация именно закреплённой версии: [v4.4.0 README](https://github.com/exceljs/exceljs/blob/v4.4.0/README.md). Проверены `workbook.xlsx.load(data)`, `cell.value.formula` / `sharedFormula`, браузерная сборка.
- Лицензия: [MIT, v4.4.0](https://github.com/exceljs/exceljs/blob/v4.4.0/LICENSE). Точная копия находится в `web/vendor/EXCELJS-LICENSE.txt`.
- `npm view exceljs version license dist.integrity --json` 16.11.2026 вернул версию 4.4.0, MIT. Версия в `package.json` задана точно, дерево зависимостей и integrity зафиксированы в `package-lock.json`.
- Браузерный файл `web/vendor/exceljs.min.js` скопирован из `node_modules/exceljs/dist/exceljs.min.js`, полученного из официального npm-пакета. Файл поставляется вместе с проектом; CDN не требуется.
- SHA-256 браузерного файла: `7e49da68588e250dbb8bba190d2caa8ab3787cc0284bda1d8b2f805c4df742c9`.
- Integrity npm-архива: `sha512-XctvKaEMaj1Ii9oDOqbW/6e1gXknSY4g/aLCDicOXqBE4M0nRWkUu0PTp++UPNzoFY12BNHMfs/VadKIS6llvg==`.

ExcelJS распространяет браузерную сборку с включёнными компонентами, например JSZip (вариант MIT), pako и lodash. Уведомления, сохранённые в исходной браузерной сборке, дополнительно перенесены в `web/vendor/BUNDLED-NOTICES.txt`; собственное авторство этих библиотек не заявляется. Наличие актуальной версии не означает отсутствие всех уязвимостей. Импорт ограничивает файл 5 МБ, ZIP до 30 МБ после распаковки, 1000 ZIP-элементов, 12 листов, 100 столбцов, 5000 строк всего; формулы, даты, ошибки Excel и объединённые ячейки отклоняются. Данные не отправляются библиотекой в сеть.

## Отпечатки решений

`web/sha256.js` — реализация SHA-256 без внешних зависимостей по [NIST FIPS 180-4](https://csrc.nist.gov/pubs/fips/180-4/upd1/final), проверенная против `node:crypto` на стандартных, граничных и Unicode-векторах. Отпечаток служит для обнаружения изменения условий и каталога; это не цифровая подпись пользователя и не система прав доступа.
